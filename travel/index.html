📄 How to Add a New Page (Copy & Paste)

Follow these 3 simple steps to create a new itinerary page in your codebase.

1

Duplicate the Template File

In your editor, navigate to src/data/pages/ and copy template.ts.

Rename the copied file to your new trip slug name (e.g. paris-2026.ts or hawaii-trip.ts).

File System Path travel/src/data/pages/template.ts ➔ travel/src/data/pages/paris-2026.ts
2

Edit Trip Fields & Slug

Open your new file and update the slug property to match your filename. Then customize title, dates, day-by-day schedule, and flight/hotel bookings.

travel/src/data/pages/paris-2026.ts 
export const paris2026Page: ItineraryPage = {
  slug: "paris-2026",
  title: "Paris & French Riviera Vacation",
  dates: "June 5 – June 18, 2026",
  schedule: [ ... ]
};
3

Register the Page in index.ts

Open src/data/pages/index.ts, import your new page, and add it to the allItineraryPages array. Save the file!

travel/src/data/pages/index.ts 
import { paris2026Page } from "./paris-2026";

export const allItineraryPages = [
  japan2026Page,
  yellowstone2026Page,
  paris2026Page, // 👈 Add your new page here!
];

✨ That's it! Once saved, your app updates automatically and the new slug card will appear on the post-login main screen!
